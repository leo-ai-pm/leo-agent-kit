## 先选入口

- 想先看操作效果：在根目录安装工坊依赖，运行 `python leo.py workshop -- ui --mock`。
- 想直接处理真实产品：先配置工坊模型，运行 `workshop -- init`，或在网页中新建。
- 已经有 PRD 和方案：运行 `init` 与 `handoff`，直接进入交付工作区。
- 只想看代码：从组件索引或工坊引擎目录进入，无需初始化项目。

## 两种工作区

| 类型 | 默认路径 | 保存什么 | 谁负责写入 |
|---|---|---|---|
| 工坊工作区 | `vendor/agent-workshop/out/<产品名>/` | PRD、方案、版本快照、骨架检查与迭代记录 | 工坊引擎；编码助手写入 `skeleton/` |
| 交付工作区 | `workspace/<产品名>/` | 交付规则、手册、产品代码、证据和阶段状态 | 编码助手与交付脚本 |

`leo.py handoff` 将两份文档从前者导入后者，保留导入时的摘要。它不迁移 `skeleton/`，也不负责之后的双向同步。
